# PM Task Assistant

Україномовний консольний помічник для Project Manager.

## Можливості

- збирає дані для нової задачі;
- запитує назву, мету, дедлайн і очікуваний результат;
- дозволяє обрати пріоритет;
- формує готову картку задачі.

## Технології

- Python 3
- Git та GitHub
- WSL Ubuntu
- Visual Studio Code
