# AI Agent Test

Учебный консольный AI-агент для начинающего Project Manager.

## Что умеет агент

- приветствовать пользователя;
- принимать вопрос или задачу;
- давать базовые ответы на типовые запросы;
- подсказывать, как сформулировать задачу: цель, срок и ожидаемый результат.

## Технологии

- Python 3
- Git и GitHub
- WSL Ubuntu
- Visual Studio Code
