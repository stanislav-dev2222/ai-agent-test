# План MVP AI-агента

## 1. Целевая аудитория
Начинающие пользователи, которые хотят познакомиться с простым AI-агентом через Python.

## 2. Проблема
Новичку может быть непонятно, как начать работу с AI-агентами и как передавать им задачи.

## 3. Цель MVP
Создать простую консольную программу, которая начинает диалог с пользователем и показывает базовый сценарий взаимодействия.

## 4. Основные функции первой версии
1. Запросить имя пользователя.
2. Поздороваться с пользователем по имени.
3. Принять простой текстовый запрос и вывести понятный ответ или подсказку.

## 5. Пользовательский сценарий
1. Пользователь запускает программу.
2. Вводит своё имя.
3. Получает персональное приветствие.
4. Вводит простой запрос.
5. Получает ответ или подсказку от программы.

## 6. Критерии готовности
- Программа запускается без ошибок.
- Пользователь может ввести имя.
- Программа выводит персональное приветствие.
- Есть понятная инструкция по запуску.
- Результат описан в README.

## 7. Риски
- Слишком сложная первая версия.
- Ошибки при вводе данных.
- Для настоящей интеграции с AI-моделью позже понадобится API-ключ.

## 8. Ограничение MVP
В первой версии не используются сложный интерфейс, дизайн и подключение внешней AI-модели. Главная цель — проверить базовый пользовательский сценарий.

## 9. Срок
Подготовить план до 21 августа 2026 года.
